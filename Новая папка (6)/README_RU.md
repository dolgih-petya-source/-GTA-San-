# GTASA CO-OP — сетевой прототип для Android

Версия: 0.1.0

## Что уже реализовано
- Режим «Создать комнату»: телефон открывает TCP-порт 7777 и ждёт одного клиента.
- Режим «Подключиться»: второй телефон подключается по локальному IPv4.
- Обмен текстовыми сообщениями в обе стороны.
- Экран статуса и журнал соединения.

## Важно
Это **только прототип проверки Wi-Fi-связи**. Он пока не подключается к GTA San Andreas,
не читает координаты CJ и не создаёт второго персонажа в игре. Для настоящего CO-OP
понадобится отдельная интеграция с игровым движком/совместимым CLEO-плагином и
синхронизация состояния игры.

## Сборка APK без компьютера
Самый простой путь — GitHub Actions:
1. На GitHub создай новый пустой репозиторий, например `GTASA-COOP`.
2. Загрузи в корень репозитория все файлы и папки из этого проекта (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и разреши запуск workflows, если GitHub попросит.
4. После загрузки файлов workflow **Build GTASA CO-OP APK** должен запуститься автоматически.
   Если нет, открой его и нажми **Run workflow**.
5. Открой завершившийся запуск и внизу страницы **Artifacts** скачай `GTASA-COOP-debug-apk`.
6. Распакуй скачанный ZIP на телефоне и установи `app-debug.apk`.
   Android может попросить разрешить установку приложений из браузера/файлового менеджера.

## Проверка двух телефонов
1. Подключи оба телефона к одной Wi-Fi-сети или к точке доступа первого телефона.
2. На первом открой приложение и нажми «Создать комнату».
3. Запиши IP сервера, показанный в журнале.
4. На втором введи IP в поле и нажми «Подключиться».
5. Отправьте сообщения в обе стороны.
6. Если соединение не устанавливается, проверьте, что оба устройства в одной локальной сети и что точка доступа не изолирует клиентов.

## Сборка локально
Требуется JDK 17 и Gradle 8.9+ с Android SDK Platform 35. На обычном Android Termux это
не является простым однокомандным процессом; GitHub Actions — рекомендуемый вариант без ПК.
